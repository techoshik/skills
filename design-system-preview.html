2. Typography (Theme.of(context).textTheme — DM Sans)

Never build TextStyle(...) from scratch — consume textTheme styles.

headlineMedium (28px, w400) — Page Hero Title
titleLarge (22px, w600) — AppBar & Major Section
titleMedium (16px, w600) — Card & Dialog Title
titleSmall (14px, w600) — List Item Title
bodyMedium (14px, w400) — Standard readable body text in plain English.
bodySmall (12px, w400) — Supporting description or helper text.
labelLarge (12px, w500, muted) — Section Label / Badge
labelMedium (11px, w500, muted) — Form Input Label
theme.mono (13px, monospace) — conn_01J9X8K2

5. Forms, Cards & Disclosure

Inputs use 40px (`inputHeight`); main cards use `radiusMedium` (16px) and nested cards use `radiusSmall` (8px).
