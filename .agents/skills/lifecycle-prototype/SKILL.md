# Prototype

1. Read [Prototype procedure](procedure.md) for phase-specific execution, required task sources, and completion criteria.
2. **For UI features, you MUST create interactive HTML/Tailwind/JS prototypes in `prototype/` with multiple design variants and data states.** (See procedure for details).
3. Execute this phase only and create/update the [Prototype artifact](../lifecycle/templates/02-prototype.md).
4. Remember to apply the framework handoff and compactness pass before presenting approval.
