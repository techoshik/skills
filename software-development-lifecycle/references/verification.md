# Verification

## Item Review

- Review changed code and affected flow.
- Run focused tests.
- Test important success and failure paths.
- Check applicable security, data, permission, and accessibility concerns.
- Confirm the item satisfies its Requirements.
- Confirm the result contributes to the Goal.
- Record evidence under Verification.
- Fix important findings before marking `Verified`.

## Goal Review

- Confirm every Step has a matching item.
- Confirm every item is `Verified`.
- Review the complete diff and flow.
- Run relevant integration and broader tests.
- Verify every Requirement and acceptance criterion.
- Check feature and module interactions.
- Check regressions and preserved behavior.
- Compare the complete outcome with the Goal.
- Reopen affected items when gaps remain.
- Revisit the plan with the user when the Goal is no longer suitable.

## Completion

- Record unresolved risks or limitations.
- Distinguish implemented, verified, QA-ready, and released.
- Summarize the outcome and evidence.
- Confirm required documentation is current.
- Confirm release readiness only after gaps are resolved.
- Require separate approval for deployment or production changes.
